# Proyecto de Automatización con Selenium

**Nombre:** Cristian Ladino

## Herramientas Utilizadas
- **Lenguaje de programación:** C#  
- **IDE:** Visual Studio  
- **Framework de pruebas:** NUnit / MSTest (dependiendo de la configuración del proyecto)  
- **Control de versiones:** Git + GitHub  
- **Automatización:** Selenium WebDriver  
- **Navegador:** Google Chrome + ChromeDriver  

---

## Gestor de Dependencias
El proyecto utiliza **NuGet** como gestor de dependencias para instalar y mantener las librerías necesarias.

---

## Librerías Empleadas
- **Selenium.WebDriver** → Control y automatización de navegadores.  
- **Selenium.Support** → Funciones adicionales para manejo de waits y PageObjects.  
- **NUnit / MSTest** → Framework de pruebas unitarias.
  
---

## Forma de Ejecución del Robot
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/CamiloLadino/PracticaSoftesting.git
   cd PracticaSoftesting
- Abrir la solución en Visual Studio:
selenium_formulario.sln
- Restaurar dependencias con NuGet:
dotnet restore
- Ejecutar las pruebas:
dotnet test
- o directamente desde el Test Explorer de Visual Studio.
